# Workflow Studio 优化设计

## 目标
将现有 Workflow Studio 调整为任务导向入口和步骤式编排，覆盖第一阶段闭环：选择目标、添加业务步骤、配置条件分支、发布前校验、运行前预览。

## 方案
在现有 `WorkflowLibrary.vue` 上增量重构，保持现有工作流定义 API 和节点数据结构兼容。入口增加任务目标与创建方式选择；左栏改为业务动作目录；中栏继续承载顺序步骤并显示分支关系；右栏按 Action 元数据渲染统一表单。条件节点使用字段/操作符/值以及 AND/OR 规则编辑器，兼容旧 expression 字段。运行时先展示摘要、风险和校验结果，确认后才调用现有运行 API。

## 数据与交互
- 业务动作映射到底层 action_id，普通用户不直接选择协议。
- 条件配置保存为 `rules`, `logical_operator`, `true_label`, `false_label`，同时保留 expression 兼容性。
- 新建流程支持模板、复制已有流程、空白流程；默认提供“设备检查流程”模板。
- 高风险动作（重启、执行操作）在运行预览中标记并要求二次确认。

## 验证
继续使用现有校验 API；前端阻止未选择目标、必填字段缺失或校验错误的发布/运行。运行成功后沿用任务监控页面。
