## 幻灯片 3: 核心问题

### 问题 #1: 伪画布设计

**现状**：垂直列表 + 下拉菜单选择上下游

**问题**：不是真正的图形编辑器

**影响**：用户期望落空，学习曲线陡峭

---

### 问题 #2: 功能缺失

❌ 无撤销/重做  
❌ 无批量任务聚合  
❌ 无智能提示  
❌ 无模板复用  

**影响**：效率低下，试错成本高

---

### 问题 #3: 心智模型不匹配

**用户期望**：图形化流程设计工具（像画流程图）

**实际提供**：列表 + 表单组合

**根本原因**：产品定位偏差

---

## 幻灯片 4: 我们的解决方案

### 分3个阶段渐进改进

```
阶段1 (2周)          阶段2 (2周)         阶段3 (2-4周)
快速见效             架构重构             功能增强
  ↓                   ↓                   ↓
图形编辑器          组件拆分            智能补全
撤销/重做           Pinia store         模板库
批量任务聚合        性能优化            快捷键系统
```

**为什么不重写？**
- 重写需要 8-10周，风险高
- 渐进改进 2周就能见效，风险可控

## 幻灯片 7: 关键设计决策

### 决策 #1: Batch Task 作为一等公民

**之前**：100台设备 = 100个独立 Task

**之后**：1个 Batch Task 包含 100个子 Task

**收益**：
- 任务列表清晰
- 支持批量控制
- 报告生成简化

---

### 决策 #2: 节点分类

**Execution Node**（执行节点）：实际执行的操作  
→ device.command、file.upload

**Control Node**（控制节点）：编译时消除  
→ utility.condition、loop.for_each

**Coordination Node**（协调节点）：运行时阻塞  
→ utility.confirm、utility.wait

**收益**：用户界面更清晰，实现更简洁

## 幻灯片 10: 风险管理

### 已识别风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| Vue Flow 集成失败 | 低 | 高 | Day 2 POC 验证 |
| 性能回退 | 中 | 中 | 每日性能测试 |
| 用户抵触 | 中 | 中 | Beta测试 + 经典模式 |

### 应急方案

- Vue Flow 失败 → 回退到列表视图，保留其他改进
- 性能问题 → 虚拟滚动、Web Worker 优化
- 用户反馈差 → 快速迭代调整
