# Tool Panel Visual Polish — Design

Date: 2026-08-07
Status: Approved (user)

## Goal

Polish the three left-drawer tool panels (临时连接 / 文件传输 / 一键大包更换) so they look
as refined as the Web home surface. Two concrete defects: (1) plain labels render with a
solid dark "black block" behind the text, and (2) the panels look gray/muddy compared to the
Web's pure-black, translucent surfaces.

## Decisions (confirmed with user)

- Direction: **translucent, breathable surfaces** — tool panels get semi-transparent deep
  cards over the pure-black `#020617` base, like the Web `--surface-*` treatment.
- Scope: **tool panels only** (临时连接 / 文件传输 / 一键大包更换) + their shared `navShell`
  shell card. Not the whole app.
- Colors: decided by me (user delegated the palette).
- Additive-only CSS in `src/styles.py` (append a new layer before `/* Global text selection */`).

## Current State (discovery)

### Black blocks behind text — root cause confirmed
- Global QSS rule `QWidget { background: #020617 }` (`src/styles.py:2753`) applies to every
  widget without a more specific rule, including bare `QLabel`s that are children of the tool
  panels.
- Tool panels sit in `QGroupBox#navShell` (`background: #0f172a`) with inner cards like
  `temporaryFormCard`, `transferConfigCard` (also `#0f172a`). A bare QLabel there inherits an
  **opaque `#020617` palette background** and renders as a dark block on the lighter `#0f172a`
  card — verified by inspecting `QLabel.palette().color(backgroundRole())` → `#020617` for the
  `系统包` form label generated by `QFormLayout.addRow(...)`.
- Adding `background: transparent` to those labels makes `palette.bg` become `#000000`
  (transparent black) — the block disappears. Root cause is the global opaque background
  cascading onto bare labels inside the tool panels.

### Gray panels
- Tool panel cards use solid `#0f172a` / `#08101d`. Web home uses pure `#020617` +
  `rgba(...)` translucent surfaces + radial glow, which reads as cleaner and less gray.

## Design

### 1. Fix black blocks — tool-panel label transparency

Append a new block in `src/styles.py`, immediately **before** the final
`/* Global text selection */` block (keeps text-selection last):

```css
/* Tool panel label transparency */
QGroupBox#navShell QLabel,
QFrame#temporaryFormCard QLabel,
QFrame#temporaryProtocolCard QLabel,
QFrame#temporaryDeviceCard QLabel,
QFrame#transferConfigCard QLabel,
QFrame#transferStatusCard QLabel {
    background: transparent;
}
```

This covers every bare QLabel inside the three tool panels, overriding the global opaque
`QWidget { background: #020617 }` cascade and removing the black blocks.

### 2. De-gray the panels — translucent deep cards

Append a second block (same layer) that overrides the tool-panel cards to translucent deep
surfaces over the pure-black base:

```css
/* Tool panel translucent surfaces */
QGroupBox#navShell,
QGroupBox#deviceDetailCard,
QGroupBox#quickActionCard,
QGroupBox#authCard {
    background: rgba(15, 23, 42, 0.66);
}
QFrame#temporaryFormCard,
QFrame#transferConfigCard,
QFrame#transferStatusCard {
    background: rgba(8, 16, 29, 0.72);
}
QFrame#temporaryProtocolCard {
    background: rgba(8, 16, 29, 0.78);
}
QFrame#temporaryProtocolCard:hover {
    background: rgba(15, 23, 42, 0.78);
}
QFrame#temporaryDeviceCard {
    background: rgba(15, 23, 42, 0.72);
}
QFrame#temporaryDeviceCard:hover {
    background: rgba(17, 28, 47, 0.78);
}
QFrame#serverCard:hover {
    background: rgba(15, 23, 42, 0.78);
}
QFrame#serverGroupHeader {
    background: rgba(15, 23, 42, 0.72);
}
QFrame#serverGroupHeader:hover {
    background: rgba(17, 28, 47, 0.78);
}
```

Border colors (`#243244`) and radius (12px) stay unchanged — only the fill becomes
translucent, so the pure-black `#020617` panel base shows through for a Web-like layered depth.
