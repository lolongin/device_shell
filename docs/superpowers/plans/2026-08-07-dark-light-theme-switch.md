# Dark/Light Theme Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a theme switch in the workspace settings toggling the whole app between 深色 (OLED 亮, default) and 浅色 (晨光), covering native Qt widgets, Web pages, and terminals.

**Architecture:** `APP_STYLE` (dark) stays unchanged (tests guard its values). A dark→light color map in `theme_tokens.py` generates `APP_STYLE_LIGHT` by string replacement. `apply_theme(mode)` re-applies the stylesheet, swaps the canvas palette, and pushes new `:root` CSS variables to each Web page via a `window.setWorkspaceTheme` JS hook. Settings combo + desktop-state persistence.

**Tech Stack:** PySide6 (QSS, QWebEngineView runJavaScript), Python, QtWebChannel, pytest.

## Global Constraints

(Values copied verbatim from `docs/superpowers/specs/2026-08-07-dark-light-theme-switch-design.md`.)

- `APP_STYLE` must stay **unchanged** (dark). Many tests assert its dark values (`#15803d`, `#22c55e`, section comments). Never edit existing rules in `src/styles.py`.
- `APP_STYLE_LIGHT` is generated by replacing every mapped color in `APP_STYLE` via `DARK_TO_LIGHT`.
- `DARK_TO_LIGHT` maps every dark color literal appearing in `APP_STYLE` / `workspace-theme.css` to its light counterpart (晨光 scheme).
- Dark (OLED 亮) is the default; light (晨光) is optional.
- Web pages gain a `window.setWorkspaceTheme(theme)` JS hook that sets `:root` CSS variables in place (no page reload flash). xterm additionally re-applies `term.options.theme`.
- `self.theme_mode: str = "dark"` default on `DeviceDesktopApp`; `apply_theme(mode)` re-applies stylesheet + canvas palette + Web variables.
- Settings panel gains a "主题" QComboBox (深色 / 浅色); `desktop_state.py` persists `theme_mode`.
- Full suite expectation: 513 passed / 3 known pre-existing failures (auto_response suggestion, temporary-panel cards, web-pages theme) — do NOT fix them; confirm no NEW failures.

def _apply_light_mapping(style: str) -> str:
    """Replace every dark literal in ``style`` with its light counterpart."""
    from .theme_tokens import DARK_TO_LIGHT

    out = style

    def apply_theme(self, mode: str) -> None:
        """Apply the dark or light theme across native, canvas, and Web surfaces."""
        mode = "light" if mode == "light" else "dark"
        self.theme_mode = mode
        from src.styles import APP_STYLE, APP_STYLE_LIGHT

        self.setStyleSheet(APP_STYLE_LIGHT if mode == "light" else APP_STYLE)
        # Canvas terminals re-read their palette from the app's palette switch.
        if hasattr(self, "apply_canvas_theme"):
            self.apply_canvas_theme(mode)
        # Web widgets push new :root variables (Task 4 wires these methods).
        for attr in ("web_shell", "device_navigation_web", "session_web_views"):
            widget = getattr(self, attr, None)
            if widget is not None and hasattr(widget, "set_theme"):
                widget.set_theme(mode)
        self.schedule_desktop_state_save()

```html
<script>
  window.setWorkspaceTheme = function setWorkspaceTheme(theme) {
    const vars = theme === 'light' ? {
      '--bg': '#f2f4f6', '--panel': '#ffffff', '--text': '#1c2128',
      '--accent': '#1f8a4c', '--muted': '#5a6470', '--danger': '#c74a4a'
    } : null;
    const root = document.documentElement;
    for (const k in vars) root.style.setProperty(k, vars[k]);
    // Rebuild the xterm theme from the (possibly updated) CSS variables.
    if (window.term) {
      window.term.options.theme = {
        background: cssVar('--bg'), foreground: cssVar('--text'),
        cursor: cssVar('--accent'), cursorAccent: cssVar('--bg'),
        selectionBackground: cssVar('--text-selection-bg'),
        selectionForeground: cssVar('--text-selection-fg'),
        red: cssVar('--danger'), green: cssVar('--accent'),
        yellow: cssVar('--warn'), blue: cssVar('--blue')
      };
      window.term.refresh(0, window.term.rows - 1);
    }
  };
</script>
```
