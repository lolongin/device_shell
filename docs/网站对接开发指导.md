# 网站对接开发指导

本文档说明如何将自有网站或后台系统接入桌面端设备运维工具。推荐方式是：自有网站提供一组 HTTP API，桌面端通过 API 模式读取设备、占用状态、连接参数，并把占用/释放操作回写到网站后台。

当前桌面端已经内置 API 客户端，主要代码位置：

- `src/api_client.py`：HTTP 请求封装。
- `src/repository.py`：把网站 API 返回数据映射为桌面端 `Device` 模型。
- `src/web_api.py`：本地示例 API 服务，可作为接口格式参考。

## 1. 对接目标

完成对接后，桌面端可以从你的网站后台获取这些数据：

- 设备列表、设备名称、领域、CPU、型号、站点等资产信息。
- 设备当前状态：空闲、已占用、流水线占用、其他。
- 占用人信息。
- SSH / Telnet 的 IP、端口、账号、密码。
- 占用、释放、切换占用状态。

桌面端连接设备时，会直接使用 API 返回的连接参数，不再要求用户手动输入 IP 和端口。

## 2. 推荐架构

```text
你的网页前端
    |
    | 调用
    v
你的网站后端 / 设备管理后台
    |
    | 提供 HTTP JSON API
    v
桌面端 device-tui
```

网站前端和桌面端都只和同一个后端交互，避免两边维护两份设备数据。

## 3. 必需接口

桌面端当前默认调用以下接口：

```text
GET  /api/devices
GET  /api/my-occupancy

POST /api/devices/{device_id}/toggle
POST /api/devices/{device_id}/claim
POST /api/devices/{device_id}/release
```

建议同时实现：

```text
GET  /api/health
GET  /api/me
GET  /api/events?since={revision}&timeout={seconds}
```

`/api/me` 是可选接口。如果你的网站没有这个接口，桌面端会优先使用 `/api/my-occupancy` 判断“我的占用”。

`/api/events` 用于长轮询通知数据变化。如果暂时不做实时通知，也可以先返回 `changed: false`，桌面端仍可通过定时刷新工作。

## 4. 接口详情

### 4.1 获取当前用户（可选）

```http
GET /api/me
```

返回：

```json
{
  "current_user": "li.wei"
}
```

如果没有该接口，返回 HTTP `404` 即可。桌面端会继续工作，并使用“我的占用”接口返回的 `device_ids` 判断我的设备。

### 4.2 获取设备列表

```http
GET /api/devices
```

返回：

```json
{
  "revision": 12,
  "devices": [
    {
      "device_id": "RTN-BJ-001",
      "display_name": "RTN-950A-BJ01",
      "domain_name": "RTN",
      "kind": "Microwave",
      "cpu_arch": "ARM-0",
      "status_code": "idle",
      "status_label": "空闲",
      "occupancy": {
        "owner": null
      },
      "connection": {
        "ssh_host": "192.168.1.15",
        "ssh_port": 22,
        "telnet_host": "172.16.1.11",
        "telnet_port": 23,
        "ssh_username": "ssh-user",
        "ssh_password": "ssh-password",
        "telnet_username": "telnet-user",
        "telnet_password": "telnet-password",
        "username": "telnet-user",
        "password": "telnet-password"
      },
      "asset": {
        "vendor": "Huawei",
        "model": "RTN 950A",
        "version": "V100R019C10",
        "site": "Beijing Tongzhou",
        "rack": "A01-U08"
      },
      "notes": "备注信息"
    }
  ]
}
```

字段说明：

| 字段 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `revision` | number | 是 | 数据版本号，设备状态变化时递增。 |
| `devices` | array | 是 | 设备数组。 |
| `device_id` | string | 是 | 设备唯一 ID。 |
| `display_name` | string | 是 | 设备显示名称。 |
| `domain_name` | string | 是 | 领域/专业/设备分类。 |
| `kind` | string | 否 | 设备类型。 |
| `cpu_arch` | string | 否 | CPU 或板卡标识，例如 `ARM-0`。 |
| `status_code` | string | 是 | 状态代码，见下方状态枚举。 |
| `status_label` | string | 是 | 状态中文显示文本。 |
| `occupancy.owner` | string/null | 是 | 当前占用人，没有占用时为 `null`。 |
| `connection.ssh_host` | string | 是 | SSH IP 或域名。 |
| `connection.ssh_port` | number | 是 | SSH 端口，默认 `22`。 |
| `connection.telnet_host` | string | 是 | Telnet IP 或域名。 |
| `connection.telnet_port` | number | 是 | Telnet 端口，默认 `23`。 |
| `connection.ssh_username` | string | 建议 | SSH 登录账号。 |
| `connection.ssh_password` | string | 建议 | SSH 登录密码。 |
| `connection.telnet_username` | string | 建议 | Telnet 登录账号。 |
| `connection.telnet_password` | string | 建议 | Telnet 登录密码。 |
| `connection.username` | string | 兼容 | 旧版默认登录账号；缺少分离字段时作为 Telnet/SSH 兜底。 |
| `connection.password` | string | 兼容 | 旧版默认登录密码；缺少分离字段时作为 Telnet/SSH 兜底。 |
| `asset.vendor` | string | 否 | 厂商。 |
| `asset.model` | string | 否 | 型号。 |
| `asset.version` | string | 否 | 软件/固件版本。 |
| `asset.site` | string | 否 | 站点。 |
| `asset.rack` | string | 否 | 机柜/机架。 |
| `notes` | string | 否 | 备注。 |

状态枚举：

| `status_code` | `status_label` | 含义 |
| --- | --- | --- |
| `idle` | `空闲` | 可占用。 |
| `occupied` | `已被占用` | 已被人工占用。 |
| `pipeline` | `流水线占用` | 被自动化流水线占用。 |
| `other` | `其他` | 其他不可明确归类状态。 |

### 4.3 获取我的占用

```http
GET /api/my-occupancy
```

接口路径固定为 `/api/my-occupancy`。

推荐返回：

```json
{
  "current_user": "li.wei",
  "revision": 12,
  "device_ids": ["RTN-BJ-001", "XTN-NJ-018"]
}
```

也支持返回设备数组：

```json
{
  "devices": [
    {"device_id": "RTN-BJ-001"},
    {"device_id": "XTN-NJ-018"}
  ]
}
```

字段说明：

| 字段 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `device_ids` | array | 推荐 | 当前登录用户占用的设备 ID 列表。 |
| `devices` | array | 可选 | 当前登录用户占用的设备列表；桌面端会读取其中的 `device_id` 或 `id`。 |
| `current_user` | string | 可选 | 当前登录用户；没有 `/api/me` 时可通过这里返回。 |
| `revision` | number | 可选 | 当前数据版本。 |

如果该接口返回 HTTP `404`，桌面端会回退到旧逻辑：使用 `/api/me` 的 `current_user` 与设备列表里的 `occupancy.owner` 比较。

### 4.4 占用设备

```http
POST /api/devices/{device_id}/claim
Content-Type: application/json
```

请求体：

```json
{
  "user": "li.wei"
}
```

成功返回：

```json
{
  "message": "Claimed RTN-950A-BJ01",
  "revision": 13,
  "device": {
    "device_id": "RTN-BJ-001"
  }
}
```

如果设备已被别人占用，返回 HTTP `409`：

```json
{
  "error": "Conflict",
  "message": "RTN-950A-BJ01 is 已被占用"
}
```

### 4.5 释放设备

```http
POST /api/devices/{device_id}/release
Content-Type: application/json
```

请求体：

```json
{
  "user": "li.wei"
}
```

成功返回：

```json
{
  "message": "Released RTN-950A-BJ01",
  "revision": 14,
  "device": {
    "device_id": "RTN-BJ-001"
  }
}
```

如果当前用户不是占用人，建议返回 HTTP `409`。

### 4.6 切换占用状态

```http
POST /api/devices/{device_id}/toggle
Content-Type: application/json
```

请求体：

```json
{
  "user": "li.wei"
}
```

推荐语义：

- 如果设备空闲，则占用设备。
- 如果设备由当前用户占用，则释放设备。
- 如果设备由其他用户或流水线占用，则返回 HTTP `409`。

### 4.7 事件通知

```http
GET /api/events?since=12&timeout=25
```

返回：

```json
{
  "changed": true,
  "revision": 13
}
```

实现建议：

- `since` 是桌面端当前已知版本号。
- 如果后台数据版本大于 `since`，立即返回 `changed: true`。
- 如果没有变化，可以最多等待 `timeout` 秒。
- 等待超时后返回 `changed: false` 和当前 `revision`。

## 5. 桌面端启动配置

PowerShell 示例：

```powershell
$env:DEVICE_TUI_DATA_SOURCE="api"
$env:DEVICE_TUI_API_BASE_URL="https://your-site.example.com"
$env:DEVICE_TUI_REFRESH_SECONDS="30"
$env:DEVICE_TUI_API_TIMEOUT_SECONDS="5"
python src/desktop_app.py
```

本地调试示例：

```powershell
$env:DEVICE_TUI_DATA_SOURCE="api"
$env:DEVICE_TUI_API_BASE_URL="http://127.0.0.1:8765"
python src/desktop_app.py
```

可用环境变量：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DEVICE_TUI_DATA_SOURCE` | `sample` | 设置为 `api` 后启用网站 API。 |
| `DEVICE_TUI_API_BASE_URL` | `http://127.0.0.1:8765` | 网站后端 API 根地址。 |
| `DEVICE_TUI_API_TIMEOUT_SECONDS` | `5` | 普通 API 请求超时时间。 |
| `DEVICE_TUI_REFRESH_SECONDS` | `30` | 定时刷新间隔。 |
| `DEVICE_TUI_CURRENT_USER` | 示例用户 | 示例服务使用的当前用户。 |

## 6. 本地联调流程

### 6.1 启动项目自带示例 API

```powershell
python src/web_api.py --host 127.0.0.1 --port 8765
```

浏览器打开：

```text
http://127.0.0.1:8765/
```

确认页面能看到设备列表，并能点击占用/释放。

### 6.2 启动桌面端 API 模式

```powershell
$env:DEVICE_TUI_DATA_SOURCE="api"
$env:DEVICE_TUI_API_BASE_URL="http://127.0.0.1:8765"
python src/desktop_app.py
```

验证：

- 桌面端设备列表来自 `GET /api/devices`。
- “我的 N”筛选来自 `GET /api/my-occupancy`。
- 点击占用后，网站页面能看到状态变化。
- 网站页面占用/释放后，桌面端刷新后能看到状态变化。
- 选中设备后，左侧连接参数能显示 API 返回的 SSH / Telnet IP、端口、账号、密码。
- 点击 Telnet / SSH 快捷按钮，可以按设备打开会话页签。

### 6.3 替换为你的网站 API

把 `DEVICE_TUI_API_BASE_URL` 改为你的网站后端地址：

```powershell
$env:DEVICE_TUI_API_BASE_URL="https://your-site.example.com"
```

然后重复上面的验证步骤。

## 7. 如果你的网站字段不同

优先建议在网站后端增加一个面向桌面端的适配接口，直接返回本文档定义的 JSON 格式。

如果不方便改网站后端，也可以修改桌面端映射逻辑：

- 文件：`src/repository.py`
- 方法：`ApiDeviceRepository._map_device()`

这个方法负责把 API 返回的 JSON 转成桌面端 `Device` 模型。

## 8. 认证与安全建议

当前 API 客户端默认没有加认证头。如果你的网站需要登录态、Token 或 Cookie，有两种推荐做法：

1. 在 `src/api_client.py` 中扩展 `HttpDeviceApiClient`，从环境变量读取 Token，并在请求头中加入 `Authorization: Bearer ...`。
2. 在内网部署一个 API 网关，由网关负责认证和权限校验，桌面端只访问网关提供的设备 API。

生产环境重点注意：

- 不要把真实账号密码直接暴露给普通网页前端。
- 只有桌面端或受控后台接口可以读取 `connection.password`。
- SSH 和 Telnet 凭据建议分离返回：`ssh_username/ssh_password` 与 `telnet_username/telnet_password`。
- 占用/释放接口必须在后端校验当前用户权限。
- 设备凭据建议从加密存储、堡垒机、密钥系统或临时凭据服务读取。
- 操作日志应记录：用户、设备、动作、时间、结果。

后续更安全的接口拆分方式：

```text
GET /api/devices
GET /api/devices/{device_id}/connection-secret
```

其中 `GET /api/devices` 不返回密码；只有桌面端准备连接设备时，再单独请求受控凭据接口。

## 9. 验收清单

后端接口完成后，按以下清单验收：

- `GET /api/me` 返回当前用户。
- `GET /api/devices` 返回设备数组，字段完整。
- `revision` 在设备状态变化后递增。
- `claim` 可以占用空闲设备。
- `release` 只允许占用人释放设备。
- `toggle` 语义符合桌面端预期。
- 冲突场景返回 HTTP `409`。
- 桌面端 API 模式可以正常显示设备列表。
- 桌面端筛选、详情、复制、SSH/Telnet 连接参数显示正常。
- 网站端和桌面端对同一设备的占用状态能同步。
- 真实环境下凭据访问有权限控制和审计日志。

## 10. 快速测试命令

检查健康状态：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/api/health
```

获取当前用户：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/api/me
```

获取设备列表：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/api/devices
```

占用设备：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri http://127.0.0.1:8765/api/devices/RTN-BJ-001/claim `
  -ContentType "application/json" `
  -Body '{"user":"li.wei"}'
```

释放设备：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri http://127.0.0.1:8765/api/devices/RTN-BJ-001/release `
  -ContentType "application/json" `
  -Body '{"user":"li.wei"}'
```
